# Faces of Figure 1

Written by `tools/figure_fonts.py`. Each face is a TrueType conversion of an OpenType face from TeX Live,
renamed with the prefix **TGP** (the GUST Font License asks that derived versions be renamed; the SIL Open Font
License reserves the name "TM Math"). Copyright notices and licence fields are kept in every file.
The faces are used only by the figure's vector text layer and are licensed separately from the book. The labels
and names of the figure are set in Segoe UI, the Windows faces of the series covers (embedded as subsets; not kept here).
