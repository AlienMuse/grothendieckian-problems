# Problem 16 · A preregistered test of the four judgments of gluing

**Kind.** Machine problem, entry level. Thesis 5 ([Report failure; abstain without evidence](../THESES.md#thesis-5)).

**Source.** *GAI-MUA: The Grothendieckian Machine* [S01], Vol. I, §15.12, p. 361 (Conjecture V1-CH-015-C001). DOI [10.5281/zenodo.23480696](https://doi.org/10.5281/zenodo.23480696).

**Status in the source.** C.

**Statement.** Test the conjecture of [S01, Vol. I, §15.12]: “On a preregistered corpus of local-to-global mathematical arguments, mandatory separation of compatibility, effectivity, uniqueness, and property return will reduce false “gluing succeeds” judgments relative to an untyped prose baseline.”

**What the source establishes.** “Testing requires fixed cases, independent reviewers, and an error taxonomy; no empirical result is claimed here.”

**Proposed by.** [S01].

**Background.** [NEDM18]; descent in [SGA4].

**Solved when.** A preregistered study as in Problem 15, reporting the result in either direction.

**Literature check (28 October 2026).** No study of this question was found.

**Discussion.** [Issue 16](https://github.com/AlienMuse/grothendieckian-problems/issues/16). Solutions, partial results, counterexamples to the problem as stated and reports that it is already solved are all welcome; see [CONTRIBUTING](../CONTRIBUTING.md).
