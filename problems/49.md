# Problem 49 · Close the formal algebra leaf

**Kind.** Formalization problem, entry level. Thesis 9 ([State what is not established](../THESES.md#thesis-9)).

**Source.** *Strained Prismatic Geometry* [S06], Problem 62.1.5 (rank 2 of the critical path), p. 1275. DOI [10.5281/zenodo.23610034](https://doi.org/10.5281/zenodo.23610034).

**Status in the source.** OPEN.

**Statement.** With pinned Lean and Mathlib versions, “Discharge PO-090 with definitions whose types separate a p-derivation from an ordinary derivation, proofs of the sum and product identities including p = 2, compatibility with the induced Frobenius lift, executable regression examples, no admitted declarations, and an axiom report containing only the approved logical foundations.”

**What the source establishes.** “This ranks second because the mathematics is known and the acceptance test is finite.” Failures of tooling do not count against the mathematics: “A library or elaboration failure is an engineering result, not a refutation.” The repository gives the statements in Lean (formal/GrothendieckianProblems/P49.lean).

**Proposed by.** [S06].

**Background.** [Joy85]; [Bui05]; [BS22]; [mC20].

**Solved when.** Proofs of the statements in formal/GrothendieckianProblems/P49.lean, with no sorry, no new axioms, and the regression examples of PO-090, checked at the pinned toolchain.

**Literature check (28 October 2026).** GitHub code search (2026-10-28) found no δ-ring or p-derivation in mathlib.

**Lean statement.** [`formal/GrothendieckianProblems/P49.lean`](../formal/GrothendieckianProblems/P49.lean).

**Discussion.** [Issue 49](https://github.com/AlienMuse/grothendieckian-problems/issues/49). Solutions, partial results, counterexamples to the problem as stated and reports that it is already solved are all welcome; see [CONTRIBUTING](../CONTRIBUTING.md).
